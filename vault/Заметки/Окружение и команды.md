## Команды

```bash
python -m pytest
```

Офлайновые тесты. Сетевые канарейки отключены по умолчанию и запускаются отдельно через `-m network`.

GUI-тесты требуют offscreen-платформы, иначе поднимают настоящие окна:

```bash
QT_QPA_PLATFORM=offscreen python -m pytest
```

Сборка — только по явной просьбе, и предварительно убедиться, что `ATSM.exe` не запущен:

```bash
python tools/make_icon.py && pyinstaller atsm.spec --noconfirm
```

## Где лежат данные

`%APPDATA%\ATSM` — `atsm.db`, `settings.json`, `logs/`, `torrents/`, `posters/`.

Переопределяется переменной `ATSM_DATA_DIR` или ключом `--data-dir` — так проверки не трогают реальный профиль.

`--no-gui` поднимает ядро без интерфейса и печатает список найденных источников: удобный способ убедиться, что плагины видны внутри собранного `.exe`.

## Особенности Windows, на которые уже наступали

- Консоль по умолчанию в cp866: без принудительного перевода в UTF-8 русские логи выглядят кашей.
- Git нормализует переводы строк. Фикстура страницы в windows-1251 должна храниться байт в байт, для этого в `.gitattributes` прописано `tests/fixtures/** -text`.
- Запущенный `.exe` держит файлы: пересборка поверх работающего приложения ломает `dist`.
