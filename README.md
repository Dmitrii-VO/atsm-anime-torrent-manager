# ATSM — Anime Torrent Subscription Manager

Десктопное приложение для Windows: следит за выходом новых серий аниме на торрент-сайтах,
показывает их единой лентой, уведомляет и отправляет раздачи в qBittorrent.

Требования и объём работ — в [ТЗ.md](ТЗ.md), план реализации — в [PLAN.md](PLAN.md).

## Запуск

```bash
pip install -r requirements.txt
```

```bash
python -m atsm
```

Первый запуск создаёт `%APPDATA%\ATSM` — база, настройки, логи, кэш торрентов и постеров.

Полезные ключи:

```bash
python -m atsm --data-dir D:\atsm-data --no-gui
```

`--data-dir` — переносной профиль вместо `%APPDATA%`, `--no-gui` — поднять ядро без интерфейса
(проверка миграций и состояния базы).

## Сборка .exe

```bash
pip install pyinstaller
```

```bash
python tools/make_icon.py && pyinstaller atsm.spec --noconfirm
```

Готовое приложение — `dist/ATSM/ATSM.exe` (около 155 МБ вместе с Qt). Папку `dist/ATSM`
можно целиком перенести на другую машину, Python там не нужен. Иконка не хранится в
репозитории: `tools/make_icon.py` рисует её кодом перед сборкой.

## Как пользоваться

1. **Добавить подписку** — вставить ссылку на страницу аниме, например
   `https://v30.astar.bz/7788-pozhiratel-zvezd-swallowed-star.html`.
   Кнопка «Проверить ссылку» покажет название и число раздач до сохранения.
2. Весь существующий архив серий импортируется молча — в ленту попадёт только то,
   что выйдет **после** подписки.
3. **Лента** — стартовый экран со всеми новинками и кнопкой «Скачать всё».
4. **Библиотека** — список подписок, детали, полная таблица раздач, контекстное меню
   (отправить в клиент, сохранить `.torrent`, открыть в клиенте по умолчанию, копировать ссылку).
5. **Настройки → Торрент-клиент** — адрес, логин и пароль qBittorrent, категория и папка
   загрузки; кнопка «Проверить соединение» покажет версию клиента.
6. Флаг «Скачивать автоматически» у подписки отправляет новые серии в клиент без участия
   пользователя.

Закрытие окна сворачивает приложение в трей: проверки продолжаются, значок показывает
счётчик новых серий, в меню трея есть «Проверить обновления» и «Скачать всё новое».

## Настройка qBittorrent

В qBittorrent: **Инструменты → Настройки → Веб-интерфейс** — включить веб-интерфейс,
запомнить порт (по умолчанию 8080), логин и пароль. Эти же значения ввести в настройках ATSM.

## Разработка

```bash
python -m pytest
```

Сетевые тесты-канарейки (ходят на реальный сайт и ловят смену вёрстки) отключены по умолчанию:

```bash
python -m pytest -m network
```

Структура:

| Каталог | Назначение |
|---|---|
| `atsm/core` | подписки, проверка обновлений, действия над раздачами |
| `atsm/db` | схема SQLite, миграции, репозитории |
| `atsm/parsers` | плагины источников и их реестр |
| `atsm/torrent` | клиенты торрентов, bencode |
| `atsm/services` | HTTP-сессия, планировщик, автозапуск |
| `atsm/gui` | окна, модели Qt, тема, трей |

Новый источник добавляется одним файлом в `atsm/parsers`: подкласс `BaseParser`
с полями `name`, `domains` и методами `fetch` / `download_torrent`. Реестр подхватит его
автоматически, ядро менять не нужно.

## Что работает и чего пока нет

Реализовано (MVP из ТЗ §27): подписка по ссылке, библиотека, лента новинок, ручная и
автоматическая отправка в qBittorrent, проверка по расписанию и при запуске, уведомления,
трей, журнал действий, диагностика источника, тёмная и светлая темы.

Состояние источников видно внизу списка подписок: «Работает», «Недоступен»,
«Ошибка парсинга» или «Изменена структура сайта» — с подробностями в подсказке.

Сверх ТЗ: карточка аниме обогащается справочными данными из **Shikimori** (оригинальное
название, тип, статус, оценка, жанры) и **AniList** (точное время выхода следующей серии).
Справка подтягивается автоматически при добавлении подписки (отключается в настройках);
кнопка «Выбрать тайтл…» правит авто-подбор, если он взял не тот сезон. Нумерация серий у
справочников своя и с трекером не совпадает — она показывается отдельно и не считается
прогрессом подписки.

Отложено: поиск по названию, правила выбора релизов,
импорт/экспорт, Telegram и Discord, Transmission и Deluge (ТЗ §28).

### Группировка подписок

Тайтлы одной франшизы («Блич» и «Блич: Тысячелетняя кровавая война») собираются в
раскрывающуюся группу — ключом служит поле `franchise` из Shikimori, а не сравнение
названий. Один и тот же тайтл, заведённый с двух источников, сливается в одну запись:
раздачи показываются вместе с колонкой «Источник», а автозагрузка включается ровно для
одного источника, чтобы серия не уехала в клиент дважды.

### Источники

**astar.bz** — один торрент на серию, без magnet и без качества.

**aniliberty.top** (бывш. anilibria.top) — JSON API. Две-три раздачи на весь релиз,
каждая содержит все вышедшие серии и обновляется по мере выхода новых. Есть magnet,
качество и кодек. Подписка добавляется ссылкой вида
`https://aniliberty.top/anime/releases/release/<alias>/`; ссылки со старого домена
тоже работают.

### Особенности источника astar.bz

Домен периодически меняется (`v19` → `v30` → …). Приложение хранит постоянный адрес страницы
и само перебирает зеркала, запоминая рабочее — подписки не протухают. Список зеркал правится
в «Настройки → Источники».

Сайт не отдаёт magnet-ссылки и не публикует качество релиза: в клиент передаётся
`.torrent`-файл, а пункты меню про magnet неактивны.

## Данные и приватность

Приложение работает только с вашей машиной: подписки, история и настройки лежат
в `%APPDATA%\ATSM`, наружу ничего не отправляется. Запросы уходят лишь к сайтам-источникам,
справочникам Shikimori/AniList и к вашему qBittorrent.

**Пароль от веб-интерфейса qBittorrent хранится в `settings.json` открытым текстом.**
Файл лежит в вашем профиле и в репозиторий не попадает, но учтите это, если делитесь
папкой данных или прикладываете её к отчёту об ошибке. Перенос пароля в Windows
Credential Manager — незакрытый пункт ТЗ §29. Логи пароль не содержат.

Если репозиторий форкается: `.gitignore` исключает `*.db`, `build/` и `dist/` —
именно там оказываются реальные подписки и собранное приложение.
